# Animex para Android TV

![Portada de Animex](branding/animex_tv_banner.png)

Aplicación no oficial para Android TV. Permite explorar catálogos de anime y guardar perfiles, listas y progreso en la TV. Los vídeos se obtienen de servicios externos y no se incluyen en la descarga.

## Instalar por primera vez

En **Downloader**, escribe solo este código y pulsa **Go**:

**`3706150`**

También puedes compartir el enlace corto [aftv.news/3706150](https://aftv.news/3706150). Apunta a la APK del último Release, por lo que el código seguirá sirviendo para futuras versiones.

Enlace directo de respaldo:

`https://github.com/Adrixton2/animex-tv/releases/latest/download/animex-tv.apk`

Descarga la APK, permite la instalación desde Downloader si Android te lo solicita y confirma la instalación. La TV debe tener Android 6.0 o posterior.

## Si ya tenías la versión antigua

La primera versión pública usa una firma de aplicación nueva. Antes de desinstalar la versión anterior, instala la [APK de migración](https://github.com/Adrixton2/animex-tv/releases/download/v0.1.153/animex-migracion-0.1.152.apk) encima, abre **Ajustes → Copia de tus datos → Guardar copia** y guarda el JSON fuera de la TV. Comprueba que la copia existe. Después instala Animex y usa **Ajustes → Copia de tus datos → Restaurar copia**. Cada TV necesita su propia copia.

Si Android rechaza la APK de migración, conserva la instalación antigua y sus datos; esa TV puede tener una firma distinta.

## Actualizaciones

Animex consulta el último Release público de este repositorio al abrirse. Cuando hay una versión con un número superior, muestra un aviso en Inicio. En **Ajustes → Actualizaciones** puedes descargarla e iniciar el instalador de Android. También puedes usar **Buscar actualización** manualmente. El sistema pedirá confirmación para instalar; la actualización conserva los datos si está firmada con la misma clave que la versión instalada.

La primera publicación es `v0.1.153`. Para versiones futuras se mantendrá el archivo `animex-tv.apk` y se incrementará el número de versión.

## Nota

Animex no es una aplicación oficial de los titulares de las obras ni de los servicios consultados. Las fuentes externas pueden cambiar o dejar de funcionar.
